# Little Garden

Little Garden is a small drawing game that turns a sketch into a detailed flower and saves it in a personal garden.

## Run it

Open `index.html` in a modern web browser. No build step or server is required.

## Publish with GitHub Pages

1. Add `index.html` and `README.md` to the root of your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. After GitHub Pages finishes publishing, open the site link shown in the Pages settings.

## Features

- Draw with a mouse, touch screen, or trackpad.
- Choose colors, adjust brush size, and undo or clear strokes.
- Name each flower and grow it from the sketch's stroke shapes, sizes, and colors.
- Keep a collection of flowers in the browser's local storage.

Garden entries are saved in the browser on the device where they were created. They do not sync between devices.
